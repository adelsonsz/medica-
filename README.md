Medica+, é um sistema criado para facilitar o cadastro de medicamentos para idosos e adultos. Percebemos que muitas pessoas (principalmente idosos), apresentam dificuldade no uso de novas tecnologias. Pensando nisso, criamos um sistema "simples", mas que funciona perfeitamente para o público alvo (os idosos). O sistema apresenta características "básicas" da programação em C, contendo um menu simples com 4 opções, 1 Cadastrar medicamento (onde também pode-se colocar o nome, quantidade, dias da semana e horarios), 2 Listar medicamento, 3 Buscar medicamento e 0 Sair. Além disso, as informações são salvas em um txt para facilitar a visualização dos medicamentos cadastrados.
